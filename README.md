# JobFlow

JobFlowは、求職活動で増えていく応募先・選考状況・返信待ち・提出物を、Google Sheets上で整理するための自主制作ツールです。応募先が増えると、企業からの返信待ちと自分の対応待ち、提出期限、面接予定が混在しやすくなります。そこで、日々の求職活動を一つの画面で把握し、次に対応すべき案件を見つけやすくすることを目的に制作しました。

## 主な機能

- 応募情報の登録・編集（Google Apps Scriptサイドバー）
- 応募IDによる安全な更新
- 選考状況、企業待ち／自分対応の管理
- 応募経過日数、返信待ち日数、要確認表示
- 履歴書・職務経歴書・ポートフォリオ等の提出物管理
- 提出期限、期限超過、未提出、提出状態要確認の一覧表示
- Dashboardによる応募状況、面接予定、提出期限の集約
- 月別応募数、応募サイト別応募数の分析表
- 月別COLUMNチャート、応募サイト別BARチャート
- 冪等なセットアップと、未知の既存データを不用意に上書きしない安全確認

## 工夫した点

- 「企業待ち」と「自分対応」を分け、次のアクションを見つけやすくしました。
- 提出物の未提出状態と提出期限を組み合わせ、期限が近い案件をDashboardで確認できるようにしました。
- 月別・応募サイト別の集計とグラフで、応募活動の状況を振り返れるようにしました。
- `setupJobFlow()`を再実行しても、既存データや正規の管理グラフを重複作成しない設計にしています。
- 既存シートに未知の値・数式・グラフがある場合は、勝手に上書きせず停止する安全確認を入れています。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `Config.gs` | シート構成、状態、表示、数式などの設定 |
| `Setup.gs` | シート初期化、既存状態の検証、Dashboard・分析表・グラフの構築 |
| `ApplicationService.gs` | 応募情報の登録・編集、入力検証 |
| `ApplicationForm.html` | 登録・編集サイドバーの画面 |
| `Menu.gs` | スプレッドシートメニューの追加 |
| `Utils.gs` | セットアップ結果・エラーの通知 |

## セットアップ

1. Google Sheetsで空のテスト用スプレッドシートを用意します。
2. Apps Scriptプロジェクトを開き、このリポジトリの6ファイルを同名で追加・反映します。
3. `setupJobFlow()`を一度実行し、必要な権限を承認します。
4. 作成された「応募一覧」「ダッシュボード」「分析」「設定」シートを確認します。

この手順はJobFlowテスト環境で確認した範囲に基づくものです。実際の利用時は、重要なデータを入れる前にコピーしたテスト用スプレッドシートで確認してください。

## 開発・検証

Stage9まで段階的に機能を追加し、JobFlowテスト環境で初回セットアップと再セットアップを確認しました。最終確認では、Dashboard、分析表、2種類のグラフ、提出期限管理を確認し、再実行後もグラフの重複や表示崩れが発生しないことを確認しています。

## 制作背景

JobFlowは、ポートフォリオのためだけに作ったサンプルではなく、自分の求職活動で発生する応募・返信・提出物・面接予定を整理するために制作した実用目的のツールです。実際の作業で必要になる情報を洗い出し、入力のしやすさ、見通しのよいDashboard、安全な再セットアップを意識して設計しました。
